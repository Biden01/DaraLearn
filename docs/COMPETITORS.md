## Чем DaraLearn уже сильнее

1. **Независимая проверка.** «Освоено» только по самостоятельному результату и отложенной проверке через 48 ч,
   а не по практике с подсказками (у AQYL и большинства — процент по практике).
2. **Решения для учителя, а не только для ученика.** Decision Engine и Teacher Action Feed: учитель принимает,
   меняет или отклоняет рекомендацию; групповые пробелы; очередь куратора.
3. **Привязка к школьному циклу.** Импорт ПҚС/БС, цель месяца к ПҚС, классы, роли школы.
4. **Доказуемый эффект.** Treatment против control, North Star, замер нагрузки учителя — у конкурентов маркетинговые отзывы.
5. **Tutor строго по проверенной учителем теории** и зовёт учителя при неуверенности.
6. Казахский и русский с первого дня.

## Чего не хватает по сравнению с конкурентами

| Функция | У кого есть | У нас | Ценность |
|---|---|---|---|
| ИИ-генерация вариантов заданий и теории с проверкой учителем | Khanmigo | Только ручной ввод и Excel | **Высокая**: банк 60 заданий против цели 150–300 |
| Неверные варианты ответа, привязанные к заблуждениям | Eedi | Гипотезы причины есть, но выводятся без дистракторов | Высокая: точнее «почему ошибся» |
| Показать решение: фото тетради и проверка шагов ИИ | Sparx, Magma | Нет загрузки изображений | Высокая: против списывания и для честного proof |
| Кабинет родителя | AQYL, Учи.ру | Нет роли | Средняя: вовлечённость, выполнение плана |
| Уведомления (Telegram/WhatsApp) ученику, родителю, учителю | Многие | Только внутри сайта | Средняя: план без напоминаний не выполняют |
| Мотивация: серии дней, цели, уровни | AQYL, Учи.ру | Серия посещаемости есть, без игровой части | Средняя |
| Живой экран урока для учителя | Magma | Тепловая карта, но не в реальном времени | Средняя |
| ИИ-помощник учителя: квиз, exit ticket, план урока по пробелам класса | Khanmigo, госплатформа | Нет | Средняя |
| Интервальное повторение освоенных навыков | Sparx, IXL | Одна отложенная проверка 48 ч | Средняя |
| Режим ЕНТ: пробные тесты в формате экзамена | AQYL, Daryn, iTest | Нет | Зависит от стратегии: ЕНТ — 11 класс, платят семьи |
| PWA / установка на телефон, офлайн | Мобильные приложения у всех | Нет манифеста | Низкая–средняя |
| Обмен с электронным журналом и Национальной базой данных | BilimClass, Kundelik | Только импорт Excel | После пилота, когда появится API |
| Более мелкий граф навыков | Squirrel AI, ALEKS | 12 навыков с пререквизитами | Растёт вместе с контентом (цель V0 — 20–40) |
