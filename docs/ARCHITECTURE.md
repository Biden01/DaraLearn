# Архитектура DaraLearn (Student Success OS, V0)

Модульный монолит: один бэкенд, одна база, разделение по модулям внутри кода.

```
Браузер ──► nginx (daralearn.kz, SSL)
             ├── /        → React (статические файлы из /var/www/daralearn.kz)
             └── /api/    → FastAPI (docker, 127.0.0.1:8000)
                              ├── PostgreSQL (docker, наружу не открыт)
                              └── AI Gateway → LLM API
```

## Модули бэкенда (`backend/app/modules/`)

| Модуль | За что отвечает |
|---|---|
| `school` | Пользователи, классы, роли: ученик, учитель, куратор, администратор |
| `content` | Карта навыков и связей между ними, теория, банк заданий |
| `events` | Учебные события: импорт Excel/CSV, проверка ответов, привязка к навыкам |
| `state` | Состояние ученика по навыкам; практика и независимая проверка учитываются отдельно |
| `decisions` | Гипотезы о причине ошибки и правила выбора следующего действия |
| `tutor` | AI-репетитор и шлюз к LLM API |
| `verification` | Проверка результата помощи, лента действий учителя и куратора |
| `plan` | Цель месяца к ПҚС, план по неделям и на день |
| `admin` | Метрики пилота, расход AI, заявки с лендинга, журнал действий |
| `leads` | Заявки с лендинга |
| `dev` | Scrum-доска команды (`/dev`) |

Цикл: событие → состояние → решение → помощь → проверка → обновлённое состояние.

## Фронтенд (`frontend/`)
React + Vite, без UI-библиотек. Два независимых чанка, маршрут выбирается в `main.jsx` по `location.pathname`:
- `/` — лендинг: `src/landing/Landing.jsx` (секции), `src/landing/text.js` (тексты из презентации),
  `src/landing/PilotForm.jsx` (заявка → `POST /api/leads`).
- `/app` — приложение (`src/app/App.jsx`): кабинеты ученика (`src/app/pages/` — план, предметы, курсы,
  диагностика, пробелы, Tutor, тесты, прогресс, календарь) и персонала (`src/app/staff/` — классы учителя,
  лента действий, случаи куратора, метрики и управление администратора, Scrum-доска команды).
  `/dev` — короткая ссылка на Scrum-доску (редирект на `/app#/dev`).

## Переменные окружения (`.env`)

| Переменная | Назначение |
|---|---|
| `ENVIRONMENT` | `production` отключает `/api/docs` |
| `POSTGRES_PASSWORD`, `DATABASE_URL` | база |
| `CORS_ORIGINS` | JSON-список разрешённых origin |
| `LLM_API_KEY`, `LLM_MODEL` | ключ и модель OpenAI для AI Tutor; без ключа Tutor работает заглушкой |
| `JWT_SECRET` | подпись сессионных JWT — обязательно задать на проде (см. `backend/app/core/config.py`) |
| `ADMIN_TOKEN` | доступ к `GET /api/leads` через заголовок `X-Admin-Token` |
